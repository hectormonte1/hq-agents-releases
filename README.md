# HQ Agents — descargas

Descargas y feed de actualizaciones (Sparkle) de la app de Mac **HQ Agents** (agents.hechq.com).

- Feed: `appcast.xml` (lo lee la app desde «Buscar actualizaciones…»).
- Cada versión está en [Releases](https://github.com/hectormonte1/hq-agents-releases/releases) como `.zip` firmado (EdDSA).

Este repositorio es público porque Sparkle descarga el feed y los `.zip` sin iniciar sesión. No contiene código ni secretos.
