# Socio — descargas

Descargas y feed de actualizaciones (Sparkle) de la app de Mac **Socio**, por OtherBot Labs (agents.hechq.com).

- **Descargar:** [Socio.dmg](https://github.com/hectormonte1/hq-agents-releases/releases/latest/download/Socio.dmg)
  — firmada con Developer ID y notarizada por Apple (desde 1.3.6): se abre sin avisos de seguridad.
  `HQ-Agents.dmg` es el mismo archivo con el nombre de antes (enlaces viejos).
- Feed: `appcast.xml` (lo lee la app desde «Buscar actualizaciones…»).
- Cada versión está en [Releases](https://github.com/hectormonte1/hq-agents-releases/releases) como `.zip` firmado (EdDSA).

Este repositorio es público porque Sparkle descarga el feed y los `.zip` sin iniciar sesión. No contiene código ni secretos.
